# College Resource Management System

A Python-based **College Resource Management System** designed to manage important college resources such as students, faculty, rooms, schedules, and classroom allocation.

## 📌 Project Overview

The College Resource Management System is a menu-driven Python application that helps organize and manage basic college resources.

The project uses separate Python modules for different management tasks, making the code easier to understand and maintain.

## ✨ Features

* 👨‍🎓 **Student Management**

  * Add and manage student information
  * Store student details such as ID, name, branch, semester, and section

* 👨‍🏫 **Faculty Management**

  * Add and manage faculty information
  * Store faculty details

* 🏫 **Room Management**

  * Manage available college rooms
  * Store room capacity and availability

* 🚪 **Automatic Room Allocation**

  * Find a suitable available room according to the required student capacity

* 📅 **Schedule Management**

  * Manage and view class schedules

* ⚙️ **Automatic Class Allocation**

  * Allocate classrooms based on available resources

* 💾 **Data Storage**

  * Store and manage project data using JSON-based data handling
